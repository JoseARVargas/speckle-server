# Instruções para agentes de IA

Ponto de entrada para todos os agentes de IA neste repositório (Claude Code, Codex). O `CLAUDE.md` importa este arquivo.

Antes de mudanças significativas, leia e siga:

- `.ai/CODING_RULES.md`: convenções de código e regras de segurança do projeto
- `.ai/ARCHITECTURE.md`: stack, estrutura e decisões arquiteturais
- `.ai/TESTING.md`: como validar mudanças
- `.ai/WORKFLOW.md`: papéis, planos, Git e deploy

## Papéis

- **Claude Code**: arquitetura e planejamento (planos em `.ai/plans/`).
- **Codex**: implementação e execução dos planos.

Detalhes em `.ai/WORKFLOW.md`. Mudanças de papel só valem quando o usuário as comunica explicitamente.
